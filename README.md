# AROS vodič za učenje

Interaktivni vodič kroz prvi deo predmeta **Arhitektura računara i operativni sistemi** (FON), Moduli 1–4.

Sadrži:
- svaki modul ispričan kao jedno povezano predavanje koje prati slajdove redom, sa slikama slajdova objašnjenim u toku priče i pitanjima „Zastani i proveri“
- mesta za nove module (dolaze nova predavanja i Operativni sistemi)
- interaktivne laboratorije i infografike: CPU vreme, Amdalov zakon, protočna obrada, simulator procesora, 9 faza ciklusa instrukcije, keš sa direktnim mapiranjem, magistrala takt po takt, prekid sa stekom, načini adresiranja, big/little endian, ASCII/UTF-8
- kviz posle svakog dela i veliki završni test (napredak se čuva u pregledaču)
- sve formule i rešene domaće zadatke

## Pokretanje

Statičan sajt bez build koraka: otvori `index.html` u pregledaču.

## Objava na Vercel

1. Na [vercel.com/new](https://vercel.com/new) uvezi ovaj repozitorijum.
2. Framework Preset: **Other**. Build Command i Output Directory ostavi prazne.
3. Deploy.

Slike slajdova su iz materijala sa predavanja i služe samo za učenje.
